## 2026-10-12 16:40 — бенчмарк доведён: тесты, открытая арена, дерево Меркла по RFC 6962, машинная сверка README
Поручение Архитектора 12.10.2026: «проверь наш бенчмарк и МАКСИМАЛЬНО его улучши, добавь ВСЁ чего не хватает и много раз
прогони проверками и тестами». Заверенные скрипты и результаты не тронуты; всё новое — отдельными файлами.
- `bench/open_arena.py` — открытая арена поиска: точный ответ, метрики, базовые методы (точный перебор, Sign-LSH,
  многотабличный LSH), подключение своего метода. Независимо повторяет заверенную строку Sign-LSH (80.50 %, NDCG 0.8715)
  и многотабличного LSH (0.10 %, 0.0022). Задержка Sign-LSH 36.8 -> ~5.5 мс за счёт подсчёта битов словами вместо
  np.unpackbits. Найдена и исправлена ошибка самой арены: точный перебор падал, если в базе не больше k векторов.
- `bench/merkle_rfc6962.py` — дерево Меркла по RFC 6962 с доказательствами включения (RFC 9162 §2.1.3.2); проходит
  векторы Certificate Transparency 1–8; корень над всеми 16 847 997 строками реального коннектома FlyWire v783.
  У заверенной схемы записаны две известные слабости (дубль последнего узла, лист = узел); заверенный файл не менялся.
- `bench/check_claims.py` — каждое число README сверяется с полем своего файла: 95 из 95. Найдена ошибка README:
  NDCG Sign-LSH 0.872 вместо 0.871 (двойное округление 0.871492 -> 0.8715 -> 0.872) — исправлено.
- `bench/reproduce.py` — одной командой перезапускает всё и сравнивает с results/. Метрики коннектома, топология и
  доли медиаторов на свежескачанных данных Zenodo совпали с заверенными 23.09 до последнего знака.
- `tests/` — набор тестов против независимых эталонов (networkx, перебор, векторы CT); `tests/mutation/run_mutants.py`
  — десять намеренных ошибок, каждая поймана своим тестом.
- CI: тесты на Linux, Windows, macOS × Python 3.10–3.13; сверка README и перепрогон на каждом push.
- `CITATION.cff` (проверен валидатором cffconvert), `requirements-dev.txt`, манифест 12.10 с меткой OpenTimestamps.
